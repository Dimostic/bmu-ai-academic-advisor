## Expected Evaluation Rules

- Handbook-specific questions must retrieve or cite `Students' Handbook 2026`.

- If a question asks "according to the handbook", CCMAS or other national documents must not override the handbook.
- Answers should admit uncertainty only when the handbook section itself does not contain the requested fact.
